# Android verification record

Status: native preview implementation; extended acceptance is in progress. The distributable is `0.1.0-preview.1` (versionCode 2), permanent package `io.github.dpan538.aether`. [BUILD.json](BUILD.json) records its inspected hash, signer, toolchain and source digest. No physical-tablet or zero-vulnerability claim is made.

## Environment and design

Actual Android API 36 ARM64 emulator, 3408×2272 surface, density 320, font scale 1.0, zero fullscreen insets. Native Kotlin Canvas/text/SVG and original GLES artwork; no WebView or whole-interface screenshot implementation. Static display-list layers record at device pixel size. Individual empty material skins are exported at 2×; the main artwork is rendered at 3801² and the selector at 966². The 1704×1136 logical frame scales uniformly with centered letterboxing at other aspect ratios.

The frozen 33-file baseline is unmodified and its shader matches byte for byte. Raw PNGs, 50% overlays, unthresholded differences, clearly labelled 4× previews and paired regions are generated by the checked-in scripts. Native font rendering and shader grain differ from Chromium. Current full-frame channel MAE is approximately 4.6–5.6/255 for the seven modern states and 4.83/255 for immersive; these are descriptive metrics, not a 100% pixel-equality result. Preset 004 uses a separately recorded browser-state recipe derived from the immutable source.

- 13 JVM unit tests passed: session/filter/selection, mute/clamp/relative gate behavior, live metadata separation, refreshed directory identity, FFT signal analysis, update host restrictions, and empty PCM pipeline buffers.
- 35 real-device-input checks passed: physical controls, 50/150 Tempo endpoints, combined filters, language, lock/light, four presets, mute restore, shared pages, triangles and retained power-off state.
- 20 edge checks passed: empty favorites, native IME, no results, station-language filter, four selector stops, dead zone, user random action, reference motion toggle and cancellation without residual detents.
- 1704×1136, 2560×1440 and 1136×1704 window adaptation passed preset hit mapping. Continuous drag and CANCEL were captured at 3408×2272; an auxiliary 1704×1136 native recording documents interaction timing without a 4K software-encoder bottleneck.
- Five native haptic checks passed after explicitly honoring Android's system switch. The emulator exposes a vibrator and records accepted calls, which cannot establish actual motor strength or tactile quality.
- OSV query of 56 locked Maven versions returned zero matched advisories at the recorded timestamp. [Full query](evidence/osv-dependencies.json). Database coverage and undiscovered defects remain limits.

Eleven live checks passed: actual AAC/MP3 decode, decoded-PCM levels, speed 1.5/0.5 with pitch 1.0, shared player while changing page, favorite save/restart/recall, foreground resume and a real HTTP-error state with cleared metadata. Final multi-state captures, native negative APK checks, actual repository download/covering install, launcher verification and the requested 300-round experience test are in progress; those pending checks are not counted as passed in this checkpoint.

## Corrections made during verification

The work found and corrected deferred-insets startup handling, browser material-export corruption, SVG aspect/menu clipping, station identity changing after a directory refresh, absolute/relative volume conflicts, repeated page toggling at lifecycle stop, and an immersive CD paint-alpha error. The new PCM processor initially rejected the pipeline’s empty end-of-stream buffer; an explicit empty-input guard and a dedicated regression test correct that playback error. A debug-only verification stream now uses an independent saved record, preserving directory results that can arrive before resource preparation completes. Cold PNG decoding and SVG preparation caused actual input-focus ANRs; both moved to a preparation worker with a bounded two-page cache. Hardware layers are recorded at native device dimensions. Capture readiness now waits for committed frames, excluding loading/splash images. Whole gestures begun during preparation/refresh/settle are suppressed, and a no-op page settle no longer blocks the following triangle tap.

The emulator accepted a framework haptic call even with the system preference disabled. The controller now checks that preference explicitly before requesting feedback; the repeat test passed. These findings are retained as iteration history, not silently removed from the record.

## Boundaries

Real mode uses actual directory fields, Media3 state/ICY metadata/decoder format, decoded PCM and Android device readings. Missing city, callsign, station time zone or programme data stay absent. The device temperature is **battery** temperature. Public directory order is retained, and queries are bounded. Reference mode is debug-only and never creates a player. Release builds always use real mode.

Only HTTPS streams are accepted. An earlier automated approval review rejected broad cleartext enablement; the implementation uses HTTPS throughout. Backgrounding pauses audio; there is no background playback service or time shift. Physical tablet performance, audible assessment and tactile strength need target-device checks. The custom canvas does not constitute complete dynamic-type/TalkBack support.
