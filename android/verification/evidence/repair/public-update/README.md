# Public preview.1 → preview.2 update proof

Old-app setup, download, permission and cancellation screenshots depict versionCode2, whose typography defect is expected and is the reason for this repair. `new-version3-current.png` is the installed final versionCode3, after the Android system Update action. The downloaded and installed binary SHA-256 is recorded in `integrity-and-preservation.json`.

The first seed fixture waited for debug-only autoplay and failed; it was corrected to press the real native Play key. That failed fixture record is retained separately and is not counted as an app pass. All successful upgrade checks use the actual Radio Browser SomaFM station UUID, favorites, volume17, Tempo90 and Chinese.
