## 产品介绍

**漫频 Aether** 是一款专注于声音纯粹性与视觉美学的电台套件。我们拒绝信息流干预、拒绝算法推荐，将调频的控制权完全交还给双手。

在这里，无线电波如同充斥宇宙的无形介质，无形，无界，却无处不在。从东京深夜的爵士窄频，到柏林地下的电子脉冲；从巴黎街头的午后谈资，再到悉尼海岸的浪潮与广播。只需轻拨旋钮，即可在星罗棋布的全球频率中自由漫游。

## 使用边界

- “电台套件”是品牌定位；当前首先规划独立的网络电台 App。
- 城市与音乐场景是品牌表达，不代表已验证的电台目录或当前节目单。
- “不设边界”表达自由探索，不承诺跨地区音源无条件可用。
- “轻拨旋钮”保留为品牌意象；具体操作方式、页面结构和控件样式留在交互与 UI 阶段讨论。
- 本文件保存品牌内容，不代表已经确定 logo、应用图标或视觉系统。

## 当前图标方向 · 2026-10-24

用户要求图标与已有现代／沉浸两页保持品牌关联，并授权 imagegen 实现[频谱球体构图](icons/2026-10-24-spectral-globes/README.md)：E1 为灰噪圆窗内的中央彩球和底部白球；E2 为上半彩面白线、下半黑面彩线的平面球体。两者继续使用已有 Aether CD 的频谱色域与印刷颗粒。

最新 [E2-v2](icons/2026-10-24-globe-structure/README.md)修复上下球面不共享结构的问题：两半引用同一套完整经纬线，只改变颜色。同一目录保存用户新要求的 F1 空结构内彩球、F2 黑白球中伸出彩手。F1／F2 为生成构图研究；E2-v2 网格为确定几何、色域为辅助生成贴图，资产性质分别记录。
