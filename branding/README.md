## 产品介绍

**漫频 Aether** 是一款专注于声音纯粹性与视觉美学的电台套件。我们拒绝信息流干预、拒绝算法推荐，将调频的控制权完全交还给双手。

在这里，无线电波如同充斥宇宙的无形介质，无形，无界，却无处不在。从东京深夜的爵士窄频，到柏林地下的电子脉冲；从巴黎街头的午后谈资，再到悉尼海岸的浪潮与广播。只需轻拨旋钮，即可在星罗棋布的全球频率中自由漫游。

## 图标探索历史

用户要求图标与已有现代／沉浸两页保持品牌关联，并授权 imagegen 实现[频谱球体构图](icons/2026-10-24-spectral-globes/README.md)：E1 为灰噪圆窗内的中央彩球和底部白球；E2 为上半彩面白线、下半黑面彩线的平面球体。两者继续使用已有 Aether CD 的频谱色域与印刷颗粒。

其中 [E2-v2](icons/2026-10-24-globe-structure/README.md)修复上下球面不共享结构的问题：两半引用同一套完整经纬线，只改变颜色。同一目录保存用户新要求的 F1 空结构内彩球、F2 黑白球中伸出彩手。F1／F2 为生成构图研究；E2-v2 网格为确定几何、色域为辅助生成贴图，资产性质分别记录。

随后用户要求将汇聚处理解成黑洞式内吸，并明确提供漏斗／双口曲面参考，指的是网格曲面的下陷与收颈。当前 [H1／H2](icons/2026-10-25-curved-throat/README.md)分别研究球内漏斗井和展开的连续双口喉道，延续彩面白线／黑面彩线。G 组平面旋涡解释仅作为误解历史；规则球面与各延展也未被选为最终图标。

用户曾认可 H1 的上方漏斗，并明确下方只要空的球面框架。[I1](icons/2026-10-25-upper-well-open-frame/README.md)据此移除下方喉管，略增上方彩色区域、采用弧形交界。H1／H2 保留为历史；整枚图标未获批准。

用户随后指出 I1 的硬分界、过正规框架和蜡笔颗粒感。[I2](icons/2026-10-25-upper-well-open-frame/I2-fluid-glass-hairline.png)尝试很细的干净线条、玻璃液体般的折射色域与梦幻流动过渡；下方空框架有机拉伸，仍无下方喉管。此研究未被选用，随后用户决定暂用 E1。
