用户随后提供绿白版，单独要求“做一下圆角”。`green-white-rounded.*` 因此只加相同圆角，不调整该版光形和配色。所提供图片与旧 J3-01 预览的 RGB 像素完全一致；PNG 从已有生产图仅作圆角裁切，内部不重新渲染。另从该版原生 SVG 增加相同裁切，保存真正矢量源文件。四角透明，圆角半径同为画布的 200／1024。

沿用参考拟合的原生曲线，以同一连续变形处理所有灰阶轮廓：圆环沿中轴向下拉长，靠近轴线略收束；星芒及两侧弧臂整体上移。原图最上方的圆环截切关系保留。直接给路径填充连续渐变，不叠加另一束光。使用明亮绿、浅金、浅粉和浅紫；不回到 magenta 高饱和色块。

1024 逻辑画布采用 200 圆角半径，内容和黑底共同裁切，四角透明；没有额外描边或立体外框。图形以同一半幅镜像，PNG 从左半像素反射，保留严格左右对称。预览页以中性浅灰底显示真实圆角。

`geometry.mjs` 保存参数、形变和颜色，`build.mjs` 导出 3072px 母版与 1024px 预览；需要 Node.js 与 sharp。`references/previous.png` 是本轮用户提供的修改前图，原样留存。

```sh
node branding/icons/2026-10-25-axial-icon/build.mjs
```

本轮没有 imagegen。J3 的旧版、其他十五张研究及独立色带声波稿保留原样；这是当前圆环／星芒方向的修订，没有替换 E1 临时应用图标。
