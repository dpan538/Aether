# Aether · 色带与声波

2026-10-25，按用户新的构图要求制作一张整体效果稿：纯黑背景，渐变矩形位于正中并贯穿左右两端，上面叠加参考中的纯白细声波线。

[预览](index.html) · [SVG 母版](spectrum-wave.svg) · [3072px PNG](spectrum-wave-3072.png)

色带从用户本轮第一张局部图的内部取十四个中值色锚，保留绿、黄、橙、粉、紫、蓝的连续过渡。去掉截图中的浅色底与边框。色带为 1024 × 216，垂直中心位于 512；高度接近参考矩形的宽高关系。黑色为 `#000000`。

三条曲线按照第二张参考的不同波形、相位及交错关系重建为三次 Bézier 路径，压到色带内部；统一为纯白 `#FFFFFF`、1.85 个逻辑单位线宽。画面没有网格、阴影、发光、纹理与文字。未强加上一轮球体研究的左右镜像要求，新构图遵循本次横向色谱和参考波形。

`references/` 保存两张本轮输入原图；`build.mjs` 保存几何与取色，`manifest.json` 保存规格和 SHA-256。需要 Node.js 与 sharp，运行：

```sh
node branding/icons/2026-10-25-spectrum-wave/build.mjs
```

这是与既有页面色谱及声音曲线相关的一张新研究稿，没有使用 imagegen；没有更换 E1 临时图标或修改冻结页面。仍需用户看整体效果后继续决定。
