## 本轮处理

- 每幅只定义一个半幅，再围绕 `x=512` 反射；所有缩放以中心为基准，没有旋转或横向偏移。J5 原参考为旋转折叠，本轮为满足镜像要求改成成对折面，不能把它称作原参考的像素复刻。
- 绿 `#4E7759`、金 `#D5BB67` 保持原色相方向，适度提亮后收回过强曝光。浅橙 `#F6B98D`、浅粉 `#FFD0DF`、浅紫 `#D5C5F4` 是依据用户最新“柔和过渡、浅粉而非 magenta”反馈作出的高光取色。
- 五版依次是提亮绿黄、浅橙高光、浅粉高光、浅紫高光、浅粉紫高光。颜色由连续色阶及原轮廓的渐变直接绘制，彩色渐变没有独立覆盖层。暖黄到浅粉的过渡区更宽，取消峰值大面积高饱和色块。
- 最新 J3 圆环沿中轴下垂 28–46 个逻辑单位，沿原细轴流向星芒；03 圆环高光从浅紫过渡到浅粉。下方绿色独立适度提亮，颜色直接绘入原轮廓的纵向渐变，没有覆盖另一束光。
- J3／J5 继续引用上一轮参考拟合路径。小幅平滑灰阶轮廓后再映射颜色，以避免高饱和色放大旧轮廓的量化噪声。细颗粒以中性标量处理。J6 保留参数射线及微粒，五版为 224／232／240／248／256 条。
- J3 的颜色直接填入原路径的纵向渐变；J5 使用连续色阶；J6 的球面使用原生渐变并保留矢量微粒；微粒坐标与半径沿用原路径，透明度归入 16 级以批量渲染。SVG 的结构、渐变、明暗及颗粒位于同一可复用半幅。为消除不同渲染器对反射滤镜和抗锯齿的取整差异，PNG 只采样一个半幅再逐像素反射；3072px 成品与 896px 预览都校验为完全左右相同。细节图来自最终成品的裁切。

## 文件

- `svg/J3-01.svg` 至 `svg/J6-05.svg`：3072 × 3072 原生矢量母版，没有嵌入位图。
- `exports/`：十五张 3072 × 3072 不透明 PNG。
- `previews/`：十五张 896px 图；`details/`：十五张 1440px 局部。
- `geometry.mjs`：半幅、镜像、色阶与形态参数；`build.mjs`：确定性导出和画廊。
- `references/original-green-gold.png`：用户重复指定的原绿金稿，与上一轮 J3 绿金预览的 RGB 像素完全相同。
- `references/prior-soft-J3.png`：本轮浅粉方案在下垂／绿光提亮前的原生渲染，供核对最新流光修改。
- `manifest.json`：源文件及产物 SHA-256；`verification.json`：实际尺寸、镜像差异、提亮与高光检查。

## 复现

需要 Node.js、sharp、Python 3、Pillow 与 NumPy；依赖不提交仓库。

```sh
node branding/icons/2026-10-25-symmetric-gradient/build.mjs
python3 branding/icons/2026-10-25-symmetric-gradient/verify.py
python3 -m http.server 4180 --bind 127.0.0.1 --directory branding/icons
```

浏览 `http://127.0.0.1:4180/2026-10-25-symmetric-gradient/index.html`。每张可放大并下载 SVG、成品和局部。PNG 是严格像素镜像；SVG 在不同渲染器下可能有亚像素取整差异。

这是参考构图的形态／配色研究，没有使用 imagegen，也没有更换当前 E1 临时图标。上一轮黑白及双色研究、原始外部参考、冻结两页均保留原样；不将参考拟合构图声称为已经批准的原创品牌成品。
