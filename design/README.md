# Aether 两页视觉基线

2026-10-24，用户决定两个页面足够，要求记录当前状态、同步仓库，并进入 Kotlin Android 实现。本决定取代早期三页规划；复古第三页只保留参考历史。

**视觉驱动，特化视觉体验。** 设计以收听、选台和手势操作为中心，保持自己的设备物性，不扩张为全能音频工作站。

| 页面 | 当前定稿状态 | 主要职责 |
| --- | --- | --- |
| 现代主页面 | v10 哑光灰拉丝金属；默认墨水与分区照明；四条同模板的长丝印引导线 | 搜索、组合筛选、收藏、调台、播放与音量、设置 |
| 纯沉浸页 | 已接受的月相艺术 CD、石墨蓝灰切台组件、暖灰白信息板 | 观赏与收听；垂直手势／两枚三角切台 |

左右滑动切换两页；共用同一播放会话。设置只在现代页大屏内，三项为语言、更新检查、About。沉浸页没有工具操作。

## 必须保留的视觉特征

- 普通中性哑光拉丝金属、独立键帽／底座、实体厚度、接触阴影；播放与 Equalizer 键不加绿色和光泽条带。
- 默认反射墨水屏；协调前光渐变；关机短暂刷新后留墨。照明与电源刷新是独立过程。
- 四枚只印台名的预设键，右上角烟色透镜下的七段指示灯；关机熄灭。
- 大轮固定光源，只转指针；小轮四条长丝印线同一圆角正交模板，等距分道，不交叉、不碰大轮刻度。
- 音量盘面无数字，外圈 0–30；相对编码器有阻尼，按下不跳值。
- 沉浸页原创窄倾斜月牙、淡金至冰蓝、稀疏信号颗粒、荧光蓝回声弧及真实比例的透明中心孔。

## 实现边界

样机数据全部 MOCK，尚无音频、实时电平或目录接入。Tempo 与 Equalizer 已有可见交互，真实音频能力并未因此确定；四维旋钮映射也是样机提案。Android 任务按[交接书](../docs/ANDROID-HANDOFF.md)忠实还原视觉，再用真实事件驱动可验证的播放状态，保留确定性的视觉对照模式。
