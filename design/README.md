# Aether 三页视觉方向

2026-10-24，用户确定三个页面、三套 UI，并强调：**漫频 Aether 是视觉驱动、视觉体验特化项目，不是全能 App。**

视觉体验决定内容取舍与操作组织。三页拥有不同的信息密度与操作氛围；功能集中服务于选台、收听和个人控制。丰富的视觉层次不要求扩张成复杂音频工作站。

## 用户已确定的页面

| 页序 | 页面 | 对应参考 | 已确定结构与用途 |
| --- | --- | --- | --- |
| 1 | 纯沉浸播放 | 图一、图二 | 以沉浸播放和视觉观赏为主 |
| 2 | 复古调节 | 图三 | 复古设备语言，按键与调节控件较多 |
| 3 | 现代主页面 | 图四 | 下部为参考图四方向的控制台；上部增加同款蓝色显示屏，展示可筛选电台，支持清晰选择与设置 |

**第三页是主页面。** 页序用于对应用户描述，不代表已确定的滑动方向或导航顺序。三套 UI 也不等于在一个布局上换三组颜色。

## 从参考中提取的视觉特征

以下是对参考图的分析，供后续原创设计使用，不是已冻结的尺寸、色值或排版。

- **图一／图二**：虹彩与光谱色同心圆、切出画面的巨大圆弧、深绿与黑色、米白印刷区、颗粒与纸面织纹、克制的小型技术排版。主视觉有足够存在感，辅助信息保持次要。
- **图三**：蓝色机身、米色面板、深色内框与红色强调；成组堆叠设备、调谐刻度、数码显示、滑杆、旋钮、成排按键。复古感来自平面色块、结构和操作节奏，不只来自材质阴影。
- **图四**：浅银灰设备外壳、蓝色电子屏、清晰黑字、分区控制台、实体按键感与音量旋钮。上方新增的电台屏幕需要与下部蓝色显示屏形成同一套设备语言。

## 元素取舍原则

- 沉浸页以观看和聆听为主，少量必要信息与操作服务主视觉。
- 复古页保留用户希望的多按键、旋钮和仪表层次；主要交互需要明确用途。
- 现代页承担实际查找与设置，清晰的电台选择是其主要任务。
- 参考图中的 EQ、Tempo、FM／AM、快进／快退和大量频率数字不自动变成产品功能。
- 真实频率缺失时不捏造 MHz；可讨论预设编号、目录位置或其他可解释的刻度映射。
- 视觉纹理、设备造型与氛围图形可以有表现性；被标注为音频、网络或地理数据的图表需要真实含义。
- 不为三个页面各自增加一套独立业务；建议三页共用电台选择与播放状态。
