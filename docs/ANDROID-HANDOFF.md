同时推进独立电台产品所需的实际播放、搜索、筛选与收藏，目录接入依据实际字段；网络、缓存、失败、取消与生命周期以实际事件验证。不能用假台标、节目、时区、码率、频谱、电量／温度或延迟填空来冒充真实数据。缺失时沿既有版式呈现自然空值。没有目录或设备条件时如实记录阻塞，仍完成可离线核验的视觉与交互工作。

Tempo 的滑块数值、Equalizer 的频谱演示、四维选择器映射是已做出的视觉交互提案，**不自动授权真实变速、音频 DSP、时移或回听**。保留设计和反馈，不因控件名称自行扩张产品能力；真实能力边界在报告中说明。未接入更新服务时保持“不可用”，不谎报最新版本。

## 画幅、文字与材质

- 参考像素 **3408×2272**，逻辑坐标 **1704×1136**，3:2 横向设计。先在该画幅精确复原，再测宽屏与较小窗口；不同设备保持构图、比例和安全区，不靠无约束拉伸。
- 现代设备组为长边 88%、短边 90%，两侧 6%、上下 5%；仪表缩半且右缘固定。窄屏和竖屏尚未设计独立重排，首轮可等比适配／留边，明确记录策略；不要自行改成通用手机卡片流。默认使用现代页。
- 沉浸主盘短边 83.64%，左／上／下及到下信息板的间隔相等；右上圆端和小盘同心完整包围。15:120 孔径比、浅孔口、金属薄边、原创新月／颗粒／蓝弧与印刷文字保持。
- 浏览器字体栈为 Arial／Helvetica Neue／PingFang SC，技术文字 SFMono-Regular／Consolas／Liberation Mono／monospace。Android 字体度量不同，不能默认 Roboto 后声称一致；测量字宽、字重、基线、字距与换行，用合法可分发字体或矢量品牌字样逐项匹配。不要从系统拷贝未获授权的字体文件。
- 现代默认反射墨水；前光上部暖白、底部冰蓝、信号仪表绿。底部播放与 Equalizer 为 **普通哑光灰拉丝金属，无绿色或亮斑条带**；独立固定底座、厚侧壁、窄倒角、干燥丝印和接触阴影。
- 四枚预设只印台名、右上 1–4 七段灯条透镜；关机不亮。大号数字字距 −0.025em，与 PRESET 间隔 0.8cqh。音量面无数字或图标，只留指针，外圈 0–30 印刷。
- 大轮光源和影子固定，只旋转指针。四条长引导线使用相同 `MVQHQVQH` 路径风格、三个 0.18cqh 小圆角、0.75cqh 等距竖线，0.13cqh 线宽，不相交、不碰大轮刻度，不改成短线或编号图例。
- 设置与四类下拉均为墨水屏内自绘样式，不能落回系统蓝色菜单或默认 Material 控件。范围窗、音频窗与左右尖括号是展示／丝印，不造按钮反馈。

在默认应用尺寸检查可读性、字距、丝印线、灯芯与按键轮廓；用户不会通过放大网页使用应用。触摸热区可在视觉轮廓外扩展，避免改变稿面。

## 交互与动画验收

按 [MOTION-SPEC](MOTION-SPEC.md)实现光、刷新、键帽行程、旋钮反馈与可选动态。连续相位使用单调时间和线性进度；实体按压／指针保留指定缓动，不把所有动画强制改成相同 LinearEasing。遵循系统减弱动画设置、前后台暂停及取消输入。

至少核验以下闭环：

1. 两页左右手势切换且电台／音量不重置；沉浸上下滑与三角切台，无工具入口。
2. 四预设、目录选台、收藏／空位、搜索与三筛选组合、无结果、重置、随机入口。
3. 设置三项、中英文、四套自绘菜单、关闭／返回、更新不可用反馈。
4. 相对音量按下不变，上下／轮缘慢拖逐格，无快速补跳；0／30 边界、静音和恢复上次音量，上方条同步。
5. 电源约 1.8 秒刷新后留图，停更新／关光／LED 灭；光键 1.05 秒渐变且不刷新；锁定／解锁与刷新期间禁用规则。
6. 大调台轮有重阻尼，慢动作有效、中心不翻转、反向无积压；四模式与图标对应，固定阴影。
7. Tempo 有足够大的拖动热区，50%–150%／5% 模拟步进；Equalizer 反馈与频谱演示；默认静态且减弱动态可用。

## 必须执行的视觉迭代

以“百分百准确”为严格还原目标，不能用一句“像素级完成”替代证据。不要改冻结稿来让比较通过。

1. 在固定 reference 模式、相同参考画幅，固定系统字体缩放／密度／安全区／语言／动画时间，截取实际 Android 内容区原始 PNG。记录 emulator 或设备型号、API、像素、density、字体、insets 和构建提交。
2. 对照至少：现代 ink、lit、settings、language-menu、genre-menu、mute、off、四号预设 `004`，及 immersive。基线七张现代全页和沉浸图均在快照目录；`004` 需按源构造同状态。额外捕获锁定、空结果与滑块边界。
3. 生成 **50% 叠加图、绝对差异图与关键区域裁图**。量化报告画幅、组件边界／间距、字形基线／换行、色值、纹理、阴影、灯条位置；同时报告全图 MAE 或差异分布。抗锯齿、字体与 GPU 差异必须解释，不能用大阈值掩盖布局偏差。
4. 逐轮修正：大几何与比例 → 字体／对齐 → 材质与阴影 → 灯光与细线 → 交互动态。每轮留关键前后对照、剩余差异与选择，直到同画幅可见偏差已解决或只剩如实注明的渲染平台限制。
5. 录制前光 0／中间／1050ms、刷新关键帧和手势／旋钮／滑块；动画测试使用可控时钟与相同取样时点。验证连续动画无突变、速度一致、取消／后台不积压，主印刷盘不自行旋转。
6. 更小与更宽的画幅检查触控、裁切和可读性。参考分辨率一致不能替代真实设备检查；模拟器截图不能宣称已完成平板实机验证。

禁止仅完成编译便结束；至少实际运行界面并查看截图。若缺少 emulator／SDK／网络权限，完成其余可做工作并准确列出依赖、已尝试动作和还缺什么，不能伪造设备测试或无限等待。
