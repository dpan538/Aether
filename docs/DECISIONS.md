## 阶段顺序

1. **视觉方向与页面元素规划（当前）**：以三页分工为依据，确定信息层级、功能取舍与控件候选。
2. **体验与交互规划**：确定任务流程、三页切换、状态与操作规则。
3. **UI 设计**：沿已确定的视觉方向细化原创布局、横竖屏与可交互原型。
4. **应用实现与验证**：接入目录、播放与平台能力，开展自动枚举和回归。

本轮用户指示已经确定三页视觉方向，并推进到页面元素规划；具体功能清单与原创视觉稿尚未冻结。四张原图和对应关系见[参考归档](../design/references/README.md)。
