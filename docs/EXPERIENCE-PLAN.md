# 漫频 Aether 体验与状态

更新：2026-10-24。当前两页已冻结，进入 Kotlin Android 实现；早期复古页撤出本轮范围。以下区分设计原型已实现的行为与真实播放器待验证行为。

## 两页关系

现代页为默认入口，负责目录、搜索、地区／类型／语言组合筛选、收藏、主动随机与设置；沉浸页以月相 CD 和节目板呈现相同会话。左右滑动切页；沉浸页上滑下一台、下滑上一台，两枚三角亦可切台。切页保留电台、音量和连接，不创建第二个播放器。

设置在现代大屏内部切换内容，只有 Language、Check updates、About。更新尚未接入，当前明确提示不可用；不伪造“已是最新”。

## 原型已实现

| 场景 | 当前行为 |
| --- | --- |
| 搜索与筛选 | 示例名称／城市匹配，三维组合，重置、无结果和结果数同步；筛选不直接替换正在展示的电台 |
| 实体调台 | 四维选择小旋钮配大轮逐格调节；指针有阻尼、死区与限幅，不排队补跳；具体维度映射仍为提案 |
| 收藏与预设 | 四枚台名键、右上 1–4 段式灯，选中亮；不足四枚的空位禁用；目录可查看收藏 |
| 静音与音量 | 0–30 相对旋钮，点击不改值；静音到 0，恢复先前音量；上方三十格同步 |
| 电源与照明 | 默认墨水；前光独立渐亮／渐暗；电源约 1.8 秒刷新后留墨，关机停止更新、关灯与熄灭预设 LED |
| 锁定 | 禁用调台、目录、设置及音量，保留解锁和灯光；电源刷新期间暂禁交互 |
| Tempo 与 Equalizer | 大滑块改变模拟数值，Equalizer 切换模拟频谱；未提供变速或 DSP |
| 动态偏好 | 默认静态，可演示频谱／虹彩；减弱动态时跳过闪烁与过渡，保留最终状态 |

精确手势、材质和时间值见 [现代页](MODERN-UI.md)、[沉浸页](IMMERSIVE-UI.md)、[动效](MOTION-SPEC.md)。

## 真实播放器需区分的状态

未播放、连接中、缓冲、实际播放、用户暂停、中断与失败应由真实播放器事件驱动。`LIVE` 表示直播属性，不等于当前有声音，也不代表零延迟。切台后不能把旧节目元数据挂在新台上；缺少台标、节目名、码率与时区是正常降级场景。

Android 保留独立的固定示例模式用于截图，真实播放模式不能显示虚构节目、测量值或连接成功。暂停恢复、备用源、随机失败重试等细节未冻结；实现任务需记录选择及验证，不擅自添加产品设置。

## 仍需保持的产品边界

搜索目标包括名称、城市、呼号，但数据完整性不能假设。公共目录顺序、同名／多音源合并、随机抽样范围、时区补充与后台播放细则仍待实现验证。收藏属于个人选择，不变成公共推荐榜。只有用户主动触发随机探索，不自动推送内容。
