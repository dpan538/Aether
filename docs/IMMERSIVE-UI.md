# Aether 纯沉浸页本地原型

三组件构图用于视觉设计，尚未连接音频。用户要求在印刷艺术 CD 方向上加入自己的元素，并与页面协调；当前保留漫频月相构图，加入淡金至冰蓝月牙与荧光蓝细节；整体改用炭黑背景、石墨蓝灰切台组件与暖灰白信息板。当前已按用户要求作为两页基线同步仓库；艺术构图不再修改。

## 设备与几何

尺寸沿用 BARO 已标记的 3408×2272 横屏（3:2）；1704×1136 是 2× 验收参考 CSS 尺寸，不是已测得的设备 DPR。

主 CD 曾采用 92.5%，后试验 75%；用户认为后者稍小，最新按用户要求在 82% 基础上相对放大 2%，当前为 **83.64% 短边直径**。设画幅 W、H，`D = .8364 × min(W,H)`，横屏主盘左、上、下留白 `M = (H − D) / 2 = .0818 × H`。

| 画幅 | CD 直径 | CD 左／上／下留白 |
| --- | --- | --- |
| 3408×2272 | 1900.3008 px | 185.8496 px |
| 1704×1136 | 950.1504 CSS px | 92.9248 CSS px |

右侧组件保持原先几何：其基准左边缘为 H，外边距与上下组件间距为 .0375H。主盘到右下面板的间距等于 M。右上向左延伸 1.25×.0375H，高度为 .3775H；其真圆端部半径为高度的一半，小盘直径为高度的 90%，两者同心、四周留边，不裁切盘面。

预览只对整页等比缩放；窄屏展示横向构图，不代表已设计竖屏产品。

## 主 CD：漫频月相构图（方向已由用户认可）

- 用户认可印刷盘方向，但要求自己的元素、与页面协调、更弯的月亮及黄绿颜色；图八保留为前期参考，不作为当前构图模板。
- 以两枚偏心圆定义更细、更弯的月牙，并偏转约 13°，形成不同的轮廓与留白。最新要求减弱整页绿调：月牙从上端淡金过渡至下端冰蓝；暗面为海军蓝炭黑，回声细弧、月相边缘与部分颗粒加入荧光蓝。
- 月相交界处保留多尺度细颗粒，暗面加入稀疏信号点和两条渐隐回声细弧，构成月相与频率的联系。颗粒使用独立盘面坐标，印刷构图固定。
- 左下为 AETHER / 漫频，下面的 PHASE 01 · FREQUENCY 随 mock 台序更新，表达视觉相位编号，不是天文数据。按最新反馈，品牌字增至 1.4cqh，相位字增至 1cqh。
- 盘面为哑光印刷，细微金属光泽位于外缘和孔口。中心孔透明，保留 15:120 的孔径与盘径比例，尺寸参考 [ECMA-130](https://ecma-international.org/wp-content/uploads/ECMA-130_2nd_edition_june_1996.pdf)。这是视觉模拟，不是标准符合性或光学测量结果；没有中心箭头。

## 右侧组件与 mock

右上保留图五逆时针 90° 的构成：石墨蓝灰面板、小虹彩盘与放大的切台三角。电台名、地区和台序位于右下角。右下暖灰白板保留技术排版、完整网格和装饰曲线，不保留阶梯状空白。

用户认可月相方向后要求放大文字。右上电台名称由 2.4cqh 增至 2.9cqh，台序由 1cqh 增至 1.25cqh，地区由 .92cqh 增至 1.2cqh；装饰套印点移到右上角，为右下信息留出空间。右下节目说明、曲目、音质、时钟与页脚辅助字也略微增加。较长电台名须与小光盘保持分离，文字不能溢出面板。

按用户授权展示四组模拟电台、节目、虚构艺人／曲目、示例码率与编码、静态当地时间。页面以 ON AIR / MOCK 明确标记；所有字段随切台同步更新。它们不是实际节目单、解码结果或实时读数。`session.mock` 为 true、connection 为 not-connected；没有音频连接。曲线与页脚 025 为装饰，不是波形或频率。

## 交互和本地查看

- 最新导航要求取代早期四向切台：上滑为下一台，下滑为上一台；两枚三角和键盘方向键继续切台。垂直拖动不足 40 CSS px 或取消时不切台。
- 左右滑动切换现代与沉浸视图，水平阈值为 72 CSS px，并须明显大于垂直位移。两页保留同一内存会话；设置中不放沉浸入口。沉浸艺术构图及定稿快照保持不变。
- 没有设置、菜单、播放／暂停或其他工具入口；设置仅从现代页进入。
- `npm run dev` 启动本地预览，`/preview.html` 显示完整 3:2 画幅，`/index.html` 为直接页面。
- `/index.html?motion=on` 可检查右上虹彩变化，遵循减弱动态偏好；主盘印刷构图固定，动效不是音频响应。
- `/index.html?render=high` 使用 2× WebGL 画布采样用于高精度导出；普通预览保持原有采样策略。
- `npm run check` 检查预览服务及浏览器模块语法。源文件位于 `design/immersive/`，无需安装依赖。

验证范围为实际浏览器中的 83.64% 直径、主盘等距、真圆背景完整包裹、颗粒与孔口呈现、WebGL 编译、mock 内容边界及切台同步。浏览器结果不代表 Android 播放、目标设备帧率、功耗或安全区验收。

本次高精度图保存在本地 `output/Aether-immersive-HD.png`，实际尺寸 3408×2272。浏览器直接重绘后截图导出，去除截图边界的一行像素并转换为 PNG，未对图像进行放大。主 CD 的 WebGL 画布为 3801×3801。当前同一获接受图已备份到 `design/snapshots/2026-10-24-two-page-baseline/renders/immersive.png`，随源码同步仓库。
