# Aether 现代主页面本地样机

2026-10-24。沉浸页已由用户接受并保存；用户已决定现代／沉浸两个页面足够，当前 v10 视觉状态冻结并授权同步仓库，进入 Kotlin Android 构建。样机没有接入音频、目录 API 或设备读数。

## 当前结构

画幅沿用 3408×2272 / 3:2，参考 CSS 尺寸为 1704×1136。设备组宽为长边的 88%，左右边距各 6%；整体高为短边的 90%，上下边距各 5%。底部控制台保持参考主体 1060:345 的比例。

上方左侧原区域仍占同一宽度。仪表组件按用户反馈缩为原宽度的 **50%**，固定右边缘；腾出的左侧放银灰控制区。上方右侧大屏与控制台右对齐。控制台与上方间距为 2.6% H，上方原左右区域比例为 43:55，栏间距为 2% W；后两项是本地排版选择。

左侧四枚方形实体键为 2×2：左上开关、右上锁定、左下设置、右下灯光。按键只叠加图标，没有可见名称；辅助技术保留操作名称。方形底座内有圆形凹面，按下有明显行程，选中后边缘微光。下方为银白大旋钮和右下黑色小旋钮。靠近小旋钮的耳机图标已按要求移除，四档现在对应电台、地区、类型和语言图标。目录中的地区、类型、城市、结果数、页脚等辅助字进一步放大，并压紧搜索与筛选区域留白，确保四行示例完整显示。

全部屏幕默认使用中性墨水材质。最新反馈取代整页绿光：灯光键统一启用照明，但目录、时钟与三十格音量条为暖白，底部播放窗、音频信息窗和范围窗口为冰蓝，仪表标签与频谱保留绿色。输出控件已按最新要求改为只有居中音量图标的实体静音键，不参与屏幕照明和墨水刷新。按钮自身的状态微光与屏幕照明分开。荧光为软件美术表达，不是对真实电子墨水面板发光原理的宣称。

底部机身保留横向拉丝、方向反射与抛光边，加入黑色操作带和屏幕密封框，减少大面积白色。收藏最新为黑色嵌框内并排的四枚实体预设键：只保留电台标题和右上角 1–4，台名居中于凹面内，使用哑光丝印色与细微覆盖纹理；编号改为烟色透镜下的七段灯条，具有暗槽、亮芯和局部光晕，关机后熄灭。删除城市、P. 前缀与其他小字。默认四组模拟收藏展示完整四键；不足四组时保留禁用空键，超过四组可水平滚动，目录收藏入口仍展示全部。下方操作区收窄，音量区有独立分隔缝并扩宽；其旋钮为 10.8cqh 实体盘面，外部有独立 0–30 刻度。播放控制键高度由 4.6cqh 增至 5.6cqh，并与预设键一起采用独立键帽和固定底座：抬起、选中与主动按压分别有明确行程；播放键的灰色凹面材质与左上实体键对应。左右尖括号现为金属面板丝印，不再作为点击按键；调台继续使用旋钮、预设及下方切台键。保留控制区微刻字与旋钮细密边纹，不改已接受的沉浸艺术。

## 开关、锁定与留墨

用户纠正了关机清空屏幕的旧表现。当前关机处理为：暂停模拟播放、停止画面更新、关闭实际照明，屏幕刷新后保留静态内容。文字、时钟数字和目录留在屏上，频谱保留最后图形；不再隐藏屏幕内容。照明偏好可在开机后恢复。

开机与电源切换使用约 **1.8 秒**刷新：先保留淡化画面，再出现黑白反相、淡残影、第二次反相，最后稳定。刷新期间暂时禁用交互；减弱动态偏好下省略闪烁。该时长是参考 Waveshare 一款模组及用户 1–2 秒要求的视觉模拟，不代表所有电子纸的通用刷新时间，也不是本项目硬件实测结果。

开机恢复当前电台和先前的模拟播放状态。锁定会禁用选台、筛选、音量、设置与旋钮；仍可解锁和控制灯光。这是当前可体验的本地交互规则。

## 双旋钮用途：当前提案

用户要求推敲右下小控件的用途，尚未批准最终映射。当前先提供如下可体验方案：

- 小旋钮选择“电台／地区／类型／语言”四个调谐维度。
- 大旋钮调整所选维度；电台档在当前筛选结果中逐格调台，其他档逐格调整对应筛选。
- 各维度独立保留，组合形成右侧目录结果；更改筛选不自动切走正在收听的电台。
- 大屏底部显示 `TUNE / ...`，当前筛选维度有细框提示。两个旋钮没有额外耳机或音量标记。
- 两个编码器支持指针旋转、滚轮、方向键及 Home/End；轻点左右半边也可步进。底部独立音量旋钮继续调整模拟音量。四档图标现为右侧金属留白中的一列丝印，可在默认尺寸识别的 0.13cqh 引导线连接各档刻度，不使用图标底板；图标由 1.5cqh 放大至 1.75cqh。 小旋钮外弧改为同心 SVG，从 −75° 到 +80°，覆盖 −60°／−20°／+20°／+60° 四档并保留端部余量，取代旧 CSS 上边框弧。

最新阻尼处理：指针转角乘 .82，主旋钮积累 .57rad、维度旋钮积累 .66rad 后才过一格；最短步进间隔 180ms，单采样限幅 .2rad。滚轮须积累 96px（单事件最多按 48px 计）才过一格。反向输入、手势结束与取消会丢弃剩余行程；快速输入不排队补跳。中心半径 20% 的轮毂不计算角度，避免 atan2 在中心附近翻转。主轮每格转 24°、以 230ms 曲线过渡，与电台数量及直接选台分离。这些是浏览器调谐手感试稿，不是物理阻尼或触觉反馈。

## 音量与范围窗口

右下音量的旧透明竖向滑条已移除。新控件是相对编码器：按下不改变音量；从轮缘开始按转角调节，从轮心开始可上下拖动。转角乘 .75、积累 .3rad 过一格；垂直积累 18 CSS px 过一格，单事件限幅且最短 140ms 步进，不保留补跳队列。细滚轮积累 120px 过一格，粗滚轮每个输入最多一格、最短间隔 160ms，孤立慢滚也可正常操作。方向键逐格，Home/End 明确到两端；0–30 档与上方音量条同步。

输出键不再显示 Stereo / Mute 文字，只保留居中图标；开机正常工作时右上指示灯为绿色，关机无色。静音时显示扬声器叉号、琥珀色指示与下压状态，模拟音量变为 0；再次点击恢复静音前的音量。音量旋钮面内不显示数字或动态图标，只保留物理指针。外圈印刷 31 个刻度，主刻度为 0、5、10、15、20、25、30；指针每档转 9° 并与三十格音量条严格对齐，辅助技术保留数值。

原铭牌区域为“当前调谐范围”窗口：显示组合筛选条件、关键词与当前结果数。用户最新明确它是纯展示框，因此移除了返回目录点击入口；辅助文字由 1.12cqh 增至 1.45cqh，结果数字由 2.5cqh 增至 3.1cqh。它与大小旋钮使用现有筛选状态，不新增独立搜索或播放器。

原 RADIO AREA 位置按最新反馈重新成为纯墨水信息窗，显示模拟码率／格式、语言／类型、当前输出档位，以及实际样机的未连接状态和 MOCK 标记。辅助字分别增至 1.18cqh、1.1cqh 和 1.08cqh。规格跟随示例电台更新，不宣称已解码或已连接音源；默认反射灰，照明后冰蓝，参与刷新与断电留图。

## 内容与功能边界

四组电台、节目、曲目、地区／语言分类、时钟、温度、电量和频谱都属于 MOCK；文字标记不冒充官方台标。预设编号与调台刻度不伪造 MHz。搜索可匹配示例名称与城市；呼号入口仍为产品目标，当前没有独立呼号数据。

目录保留搜索、组合筛选、无结果、重置、收藏、主动随机选择与设置内容切换。Tempo 按最新参考改为大尺寸实体滑块：黑色导轨、上下刻度和 3.8cqh 圆形拨钮，支持手势拖动及键盘，数值试稿为 50%–150%、每格 5%。当前仅改变样机数值，没有音频变速。Equalizer 加高至 4.25cqh，采用独立键帽与固定底座，目前用于预览模拟频谱，没有 EQ、回听或快进能力。频谱默认静止，动态仅为演示且遵循减弱动态偏好。

设置使用常见齿轮图标，只有语言切换、Check updates 与 About。语言可切换中英文；更新入口目前提示更新服务不可用，尚未接入实际服务，不虚构版本检查结果；About 展示品牌与样机版本。设置中没有沉浸入口。现代与沉浸页通过左右滑动切换，沉浸页上下滑动仍切台，双方共享电台状态。

目录设备下沿的 LINK / AUDIO / VISUAL 状态灯分别表达连接、播放与动态：启用或连接为绿，未连接／未启用为橙，关机无色，连接故障或权限问题为黄。当前未接音源，连接与音频灯为橙色。该映射已做纯函数检查，黄色与绿色连接态尚不是实测平台事件。

原窄条替换为三十格音量控制，显示 00–30 档；与底部音量旋钮双向同步。每格对应总音量的 1/30，内部仍保存 0–100 的模拟音量值。

所有部件用 HTML/CSS/SVG 重建；未把参考图当作整块界面贴图。原始设计参考按字节保存，问题定位用的应用截图不混入艺术参考。


## 最新默认尺寸与前光细化

设置页改用与目录相同的索引、文字、分隔线和墨水材质，仍只有语言、检查更新和 About；页眉随视图改为 AETHER / SYSTEM。界面语言也使用自绘菜单，已验证中英文切换、更新服务不可用提示与 About 展开。全部筛选下拉菜单在墨水屏内部自绘，不再出现系统蓝色菜单：底色跟随默认墨水／暖白照明，选项使用印刷字、细分隔、深色反选墨块和勾选。支持点击、方向键、Home/End、Enter、Escape 与点击外部收起；保留底层筛选状态供大小旋钮组合调谐，开关／锁定照常禁用。右侧外壳四枚星号装饰已移除。

底部预设、播放键和 Equalizer 统一加强实体材质：窄倒角、厚侧壁、独立底座、硬接触阴影、矩形浅凹面和哑光丝印，减少椭圆凹槽及发光边框。选中仍通过键帽行程和原有预设 LED 表达。Tempo 拨钮改为带细齿外缘的实体握持件。 最新播放键和 Equalizer 去掉绿色与镜面反射条带，改用普通的灰色哑光拉丝表面，仅保留细纹、侧壁及接触阴影。大号预设数字字距由 −0.075em 调至 −0.025em，PRESET 间隔由 0.4cqh 增至 0.8cqh；004 状态未溢出。宽窗口内保持设备 3:2 比例并居中，避免按键区域挤压大波轮或设置内容。

大波轮表面高光、拉丝和投影固定于同一光源，只旋转指示标记，避免转动时阴影跟着转或档位反馈改变投影。小旋钮的四条长引导线保留早期克制的折线排布，竖线等距为 0.75cqh；四条使用完全相同的路径命令和三个 0.18cqh 小圆弧转角，统一档位端与图标端的接入方式，去掉长 S 弯和单独的大回环。几何采样检查四路无交叉，避开大波轮刻度。

灯光切换采用约 1.05 秒的连续亮度渐变，墨水内容位置保持固定；仪表、频谱与屏幕颜色都由同一进度控制。点亮与熄灭不触发黑白刷新，电源切换仍保留原 1.8 秒刷新。减弱动态偏好下省略渐变。E Ink 的[前光资料](https://www.eink.com/tech/detail/Front_Light)和 Inkplate 的[白色 LED 与亮度控制文档](https://docs.soldered.com/inkplate/6flick/hardware/frontlight/)支持将照明作为独立亮度控制的处理；1.05 秒曲线为本地体验选择，不是 LED 的固有启动时间或实测波形。

## 研究依据及推理边界

- [Fluke 101 用户手册，Rotary Switch / Functions](https://media.fluke.com/43695427-8f3d-4217-bfef-b10800c0e252_original%20file.pdf)：用于比对实际档位与功能标记的关系；Aether 按用户最新选择保留长引导线，曲线路由为本地美术排版。
- [E Ink：Benefits / Bi-Stability](https://www.eink.com/tech/detail/Benefits)：电子墨水图像在断电后可以保持。因此“留图”不等于设备仍须供电。
- [Microchip：ePaper Display Fundamentals](https://developerhelp.microchip.com/xwiki/bin/view/software-tools/mgs/dev-kits/epd-ug/fundamentals/)：全刷新可能出现可见闪烁；刷新模式不同于持续维持画面。因此本项目选择在关机前做一次刷新，是体验模拟，不声称所有面板关机都会闪。
- [E Ink：Front Light](https://www.eink.com/tech/detail/Front_Light)：真实电子纸借助环境反射光，暗处可加前光。本项目沿用户指定的荧光视觉做艺术化照明，未实现面板驱动或验证节电效果。
- [Waveshare：5inch e-Paper](https://docs.waveshare.com/5inch_e-Paper) 及其[刷新 FAQ](https://docs.waveshare.com/5inch_e-Paper/FAQ)：该模组标称全刷新 1.8 秒，并说明全刷新闪烁用于清除残影。对照了厂商实物图的灰白底与深色字，作为本轮材质和刷新模拟依据。
