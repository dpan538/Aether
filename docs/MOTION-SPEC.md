# Aether 动效与输入规格

2026-10-24 两页冻结基线。下列数值从当前代码提取；它们是视觉样机选择，不是物理阻尼、硬件电子纸波形或 Android 性能实测。Android 在保持效果和状态时用平台可控时钟实现，依据真实运行验证。

## 时间与曲线

| 对象 | 当前效果／时序 | Android 还原要求 |
| --- | --- | --- |
| 前光 | `--frontlight` 0↔1，1050ms，cubic-bezier(.22,.08,.24,1)；暖白／冰蓝／绿共享进度 | 连续渐亮渐暗，内容固定；反向操作从当前亮度继续；灯光键不触发墨水刷新 |
| 电源刷新 | 1800ms `steps(1,end)`，交互锁到1850ms | 0–14% 降对比；22–38% 反相；44–58% 淡残影；64–73% 二次反相；80–91% 轻残影；100% 稳定，具体色值取源关键帧 |
| 上部实体键 | transform／shadow 90ms，background 130ms，边缘光opacity 120ms | 底座固定、键帽有按下与抬起行程，选中和主动按下区别；不是整块界面平移 |
| 预设／播放／EQ | 主体键帽行程90ms；预设与输出部分shadow／border 100–120ms | 台名丝印跟随帽面，段式灯位于独立烟色槽，选中亮、断电熄灭 |
| 大调台轮 | 每格指针24°；230ms，cubic-bezier(.16,.72,.2,1) | 大轮阴影和面纹不旋转，只转指针；方向与输入一致，独立于目录数量 |
| 小选择轮 | 四档−60°、−20°、+20°、+60°；230ms同曲线，外弧−75°至+80° | 接点和图标对应；四条丝印线保持静止 |
| 音量指针 | 每格9°，0–30共270°；180ms，同(.16,.72,.2,1)曲线 | 先提交离散档值，指针平滑追随；不能积压补跳 |
| Tempo | 50%–150%，每5%；3.8cqh大拨钮随手势 | 触点与拨钮一一对应，不加追赶惯性；保持现有轨道和上下刻线 |
| 沉浸小虹彩盘 | 可选 `motion=on`，单调时间秒值线性输入着色器；浏览器约24fps绘制 | 相位连续，不在循环边界跳变；平台绘制可随刷新率，效果速度按秒值保持 |
| 现代频谱 | 可选，按requestAnimationFrame时间驱动sin/cos的示例柱高；默认静态 | 在reference模式保持确定性；无真实音频时标记模拟，真实模式不能伪造响应 |
| 页面切换 | 浏览器已实现手势与会话保留；宿主直接显示目标页，尚无冻结切页过渡时长 | Android 补足随手势的连续水平过渡；可用线性拖动进度，释放收束参数记录为实现选择，不假称已有定稿 |

前光并非使用线性曲线；“适配线性动画”要求的是连续相位／进度场景使用线性时间，不能将已有实体缓动全部替换。主 CD 印刷构图固定，不旋转，不附加呼吸／视差／整体缩放来填动效。

## 阻尼与手势

- 主轮：角度增益.82、单采样限制.2rad、累计.57rad一格；小轮累计.66rad；步进最短180ms。滚轮累计96px，单事件最多48px。中心半径20%不算角度；结束、取消、反向清除残量；没有后续补跳队列。
- 音量：轮缘角度增益.75，单事件限幅.12rad，累计.3rad一格；中心竖拖累计18逻辑px一格、单事件9px上限；最短140ms。细滚轮累计120px；粗滚轮最多一格／160ms。按下不改值。静音存前值并到0，第二次点击恢复。
- 沉浸垂直≥40逻辑px且竖向大于横向才切台；横向≥72px且超过竖向1.3倍切页。现代横向导航避开输入／滑块／旋钮热区，不抢走操作手势。
- 触摸坐标映射到设计逻辑坐标再计算阻尼。不能把浏览器物理像素阈值直接当不同density设备的px；热区可扩但视觉轮廓不变。

## 状态与性能

关机保留最后墨水内容和频谱形状，停止画面更新、前光和LED。开机恢复当前台和前次播放意图；真实播放器恢复须受系统音频事件制约。锁定禁用调台、筛选、设置和音量，保留解锁与灯光；刷新期间暂禁交互。

减弱动态：跳过闪烁、过渡和演示动态，保留最终状态与手势功能。后台／页面销毁停止无用绘制，不累积计时队列；返回不爆发补帧。连续动画按单调时间计算，测试模式可固定相位／时间。

检查前光起点、中点、终点，刷新关键帧，按键按下／释放，旋钮慢拖／快拖／反转／中心与边界，滑块拖动与取消。实际帧率、能耗及触觉效果需要设备证据；当前浏览器冻结包未证明这些指标。
