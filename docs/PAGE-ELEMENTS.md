# Aether 当前两页元素

2026-10-24 固定当前视觉状态。早期“第一／第三页”编号仅用于历史参考，当前只有现代、沉浸两个主页面。设置与下拉是现代屏内状态，不是新增主页面。

## 现代主页面

| 区域 | 固定视觉／行为 |
| --- | --- |
| 左上控制面板 | 2×2 图标实体键：电源、锁定、设置、灯光；银灰大调台轮、黑色四档小轮；四图标丝印列与有序长引导线 |
| 上部仪表 | 原区域半宽、右缘固定；双表、时钟、十段频谱；所有当前读数标记 MOCK |
| 右上大屏 | 墨水目录；搜索、地区／类型／语言自绘菜单、四行示例、状态与结果；屏内设置为统一索引行 |
| 大屏下沿 | 三十格音量条；目录／收藏／设置／随机实体导航；LINK／AUDIO／VISUAL 灯 |
| 下部左侧 | 大预设号与 PRESET、节目／台名、印刷调台刻度与尖括号、收藏和动态键、只读范围／结果窗 |
| 下部右侧 | 只读音频信息墨水窗；图标式静音实体键，正常绿灯、静音琥珀灯、关机无色 |
| 收藏预设 | 四枚独立键帽，只印台名；右上 1–4 七段指示灯置于烟色透镜下；选中亮、关机灭 |
| 下部操作带 | 大实体 Tempo 拖动滑块、加高 Equalizer、五枚哑光灰拉丝播放／切台键；明确厚度与按压行程 |
| 音量区 | 空白实体轮面与指针，外圈 31 刻度及 0／5／10／15／20／25／30，阻尼相对输入 |

底部键使用普通拉丝金属，不加绿色和抽象反光条带。台名像印在键面上，数字像真实灯条。大号预设字距为 −0.025em，PRESET 间隔为 0.8cqh。

## 纯沉浸页

| 区域 | 固定视觉／行为 |
| --- | --- |

| 右下信息板 | 暖灰白印刷与网格；模拟节目、曲目、规格、时钟和装饰曲线；保留 MOCK |
| 导航 | 水平切现代／沉浸，上下及三角切台；无设置、播放键、菜单、收藏或工具入口 |

## 样机不等于产品能力

两页共享状态。当前没有真实流、实时频谱、测温或电池测量。Tempo 的 50%–150% 数值、Equalizer 的频谱演示和四维调谐是已有可体验提案，不自动冻结真实变速／DSP。不得加入早期复古页、FM／AM、节目回放或其他未确认功能来填充控件。

尺寸与状态以[快照](../design/snapshots/2026-10-24-two-page-baseline/README.md)及两份具体 UI 文档为准；Android 对照规则见[交接书](ANDROID-HANDOFF.md)。
