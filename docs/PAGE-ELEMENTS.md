# Aether 三页元素规划

更新日期：2026-10-24。**视觉驱动，特化视觉体验；功能服务于选台和收听。** 三个页面及参考方向来自用户决定；以下具体元素配置是首轮草案，尚未冻结。

本轮规划页面需要什么，不制作最终布局或加入应用实现。[四张原图](../design/references/README.md)已保留，[视觉方向](../design/README.md)说明图号与页面的对应关系。

## 已确定的结构

1. 第一页为纯沉浸播放，参考图一、图二。
2. 第二页为复古调节，参考图三，按键与调节控件较多。
3. 第三页为现代主页面，下部参考图四；上部增加同款蓝色显示屏，展示可筛选的电台选项，并能进行设置。

这些是页面的职责。具体信息摆放、控件数量、切换手势和屏幕比例仍待讨论。

## 第一页：纯沉浸播放

这一页值得在收听时长时间停留。主视觉占据注意力，电台信息和操作保持克制。

| 元素候选 | 作用 | 当前建议 |
| --- | --- | --- |
| 虹彩同心圆／圆弧主视觉 | 建立图一／图二方向的沉浸体验 | 作为核心；尺寸、构图与动态规律后续设计 |
| 电台名称与台标 | 知道正在听哪个台 | 保留，避免与主视觉争抢；台标缺失有占位 |
| 国家／地区 | 感知声音的来处 | 少量文字，城市有可靠数据时补充 |
| 当前节目／曲目 | 呈现正在播出的内容 | 有元数据时出现；没有时自然收起 |
| 直播与实际播放状态 | 识别直播、暂停、缓冲和断连 | 始终可理解，状态反馈融入画面 |
| 播放／暂停 | 最基本的收听控制 | 保留，显隐方式待讨论 |
| 返回现代主页面的途径 | 随时重新选台 | 需要容易发现，具体形式待定 |
| 收藏、当地时间或音频规格 | 补充信息与轻量操作 | 可选，避免把所有指标搬入沉浸页 |

参考图中的大段说明、日期表格和曲线提供排版气质，不自动要求复制成业务模块。装饰图形可以表达氛围；如果标注为频谱、电平或连接数据，就需要对应真实数据。视觉动画是否随音频变化仍未确定。

## 第二页：复古调节

这一页保留图三的设备堆叠、旋钮和按键丰富度。内容围绕收听组织，实际能力与装饰结构分开。

| 元素候选 | 作用 | 当前建议 |
| --- | --- | --- |
| 多层设备面板、内框与分隔 | 形成复古系统的整体结构 | 视觉骨架；层数与比例待定 |
| 调谐刻度与指示针 | 表达正在选择的位置 | 优先讨论映射到电台／预设的位置，不伪造频率 |
| 电台信息显示窗 | 显示名称、地区与当前节目 | 统一表达当前电台，避免多个窗口重复同一信息 |
| 播放／暂停键与状态灯 | 直接控制收听，反馈连接状态 | 基础控制候选 |
| 音量旋钮 | 提供明确的调节手感 | 建议保留，应用音量或系统音量的语义待定 |
| 收藏／预设按键组 | 快速切换用户常听的台 | 按键丰富度的主要用途候选；空位行为待定 |
| 上一个／下一个电台 | 在明确集合中切台 | 是否提供及其集合由后续规则确定 |
| 随机调频键／旋钮动作 | 主动探索未知电台 | 已有功能的复古表达，动作映射待定 |
| 连接仪表或音频电平窗 | 提供设备反馈 | 分开表达网络与声音；VU 仍为候选能力 |
| 返回现代主页面的途径 | 回到搜索、筛选和设置 | 与三页导航一并讨论 |
| 时钟或音频规格窗 | 增加少量可信细节 | 可选；不为填满面板增加重复读数 |

参考图上的多段 EQ、推子和按钮数量不代表需要同等数量的音频处理功能。面板结构、刻线、接缝和非交互细节可以丰富；可点击控件则需要明确反馈与实际用途。

## 第三页：现代主页面

这是主要入口，承担清晰选台与设置。用户已确定“上部蓝色电台屏幕＋下部图四方向控制台”的关系，具体尺寸尚未确定。

### 上部：电台屏幕

| 元素候选 | 作用 | 当前建议 |
| --- | --- | --- |
| 与图四同款的蓝色显示屏 | 统一上下设备的视觉语言 | 已确定的方向；不把它做成无关风格的通用网页信息流 |
| 名称／城市／呼号搜索 | 直达目标电台 | 主要操作，搜索规则与数据补充另行细化 |
| 国家／地区、类型、语言筛选 | 缩小查找范围 | 主要内容；已选条件可见，并能清除 |
| 电台选项 | 显示可选择的结果 | 建议名称、台标、地区为基本项；其余按信息密度取舍 |
| 收藏标记与当前播放标记 | 识别个人选择和正在收听的台 | 和公共排序分开；是否有收藏专用内容状态待定 |
| 结果数量、空结果、加载／失败 | 说明当前查找发生了什么 | 轻量表达，不占据整屏注意力 |
| 设置入口及设置内容状态 | 在主页面完成必要设置 | 位置已确定在此页；具体项、局部面板或屏幕内容切换未定 |

### 下部：现代控制台

| 元素候选 | 作用 | 当前建议 |
| --- | --- | --- |
| 蓝色当前电台显示窗 | 延续图四的标志性显示屏 | 改为真实电台身份或明确预设编号，不填假 MHz |
| 正在播出信息 | 呈现名称、节目和播放状态 | 与上屏结果区分，表示实际正在收听的台 |
| 播放／暂停与缓冲反馈 | 稳定、明确地控制声音 | 基础控制候选 |
| 音量旋钮 | 保留图四明确的实体控制感 | 建议保留，语义与复古页一致 |
| 收藏与常听快捷位 | 快速调取个人电台 | 沿用已提出的收藏能力；数量和形式待定 |
| 调谐刻度与切台动作 | 保留设备意象 | 先确定电台集合和刻度含义，再设计细节 |
| 随机调频入口 | 进入探索 | 是否放在下部控制台待定 |
| 进入沉浸页、复古页的途径 | 使用另外两种体验 | 必须可达，具体导航方式未定 |
| 码率／编码、当地时间 | 可信且克制的补充信息 | 候选；避免上屏与下部堆叠重复数据 |

图四中的 Tempo、Equalizer、快进／快退、FM／AM、Stereo 按键和定时器只作为参考图内容记录，不自动变成 Aether 的已批准能力。设置由此页承载，不因此增加第四个主页面；具体承载方式仍待讨论。

## 三页共用的内容与后续问题

建议三页操作同一电台与播放状态，跨页时声音连续。三页不需要各自复制全部信息或提供独立设置；设置的主要归属为现代主页面。

优先继续明确：

1. 每页元素中哪些保留为常驻、哪些次要或不需要。
2. 复古预设按键、调谐刻度与切台集合的真实动作。
3. 上部蓝色屏幕在结果、收藏与设置之间的内容组织。
4. 三页切换的路径，以及沉浸页基本操作的可发现性。
5. 主视觉的动态方式、连接仪表与音频电平是否进入首轮设计。

本轮以用户给定的三页视觉目的为依据，不追加全能功能清单，也不把上述候选项写成已确认需求。
